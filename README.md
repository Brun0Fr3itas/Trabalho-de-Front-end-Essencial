## 📌 Sobre o Projeto

Site temático da **Copa do Mundo FIFA 2026** 🏆 com foco na 🇧🇷 **Seleção Brasileira**, desenvolvido em grupo para a construção de uma interface moderna e responsiva. O projeto conta com as seguintes páginas:

- 🏠 **Home** — Página inicial com destaques e informações gerais sobre a Copa
- ⏱️ **Temporizador** — Contagem regressiva para o início da competição
- ℹ️ **Sobre** — Informações sobre o projeto e a Seleção Brasileira
- 📬 **Contato** — Formulário para entrar em contato com a equipe
- 🏆 **Ranking** — Classificação e desempenho das seleções na competição
